          Cómo funciona RTP

          1. Completa los datos del trabajo y acepta la declaración.
          2. Registra cada interacción con la IA: modelo, tipo de acceso, adjuntos y el prompt exacto.
          3. Exporta el JSON al terminar y entrégalo junto con la memoria. Si más adelante necesitas continuar un registro, usa «Cargar JSON» para recuperarlo y seguir añadiendo iteraciones.

          Los adjuntos se guardan comprimidos dentro del JSON y puedes descargarlos de nuevo desde la línea de tiempo con el botón «Descargar». Los registros antiguos que solo conservan la huella se marcan como «Solo huella».

          El panel «Ver JSON» muestra una vista previa en vivo. Copiar no marca el registro como exportado; descargar sí.

          Todo se guarda en tu navegador. RTP no envía datos a ningún servidor. Los adjuntos se comprimen con gzip y se incrustan en el JSON para que puedas recuperarlos; no se cifran.

          Cada adjunto incrustado ocupa espacio en el JSON y añade aproximadamente un 33 % por la codificación base64. Los archivos ya comprimidos pueden no reducirse.

          La cadena de integridad permite detectar ediciones posteriores a la exportación, pero no sustituye a la defensa oral ni a la revisión docente.
